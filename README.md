# 🌳 树洞挚友（AI Treehole）

> 把心事讲给树洞听：一个 **AI 对话树洞**——所有对话记录自动同步到 **飞书云文档**；
> 大脑实时扫描解读你的 **性格 · 情感 · 情绪**，持续建立 **人格画像模型**；
> 在倾听者 / 交流者 / 分享者 / 安抚者四种身份间自动切换，做你随叫随到的 **AI 挚友**。

---

## 一、设计理念

「树洞」是一个只属于一个人的私密空间。这个项目把它做成一个本机运行的 Web 应用：

| 你想要 | 它怎么做 |
|---|---|
| 一个能说真心话的地方 | 本机运行（127.0.0.1），记录同步到**你自己的**飞书云文档，不经任何第三方 |
| 记住我说过什么 | 每天的对话自动写成一篇飞书文档（按轮次、带情绪标注）；每 8 轮生成对话小结 |
| 越来越懂我 | 每条消息先做**情绪快扫**（情绪词/强度/话题/风险），累计后做**深度人格分析**，维护一份会成长的人格画像 |
| 像朋友，不像客服 | 四重角色提示词：🫂倾听 / 💬交流 / ✨分享 / 🕊️安抚，按你的状态自动切换（也可手动指定） |
| 出事时拉我一把 | 自伤/绝望信号触发**守护模式**：直接表达关心 + 心理援助热线，不说教不回避 |

## 二、架构

```
浏览器 UI（深夜森林主题 · SSE 流式对话）
   │  fetch SSE
   ▼
FastAPI  app.py  ─── http://127.0.0.1:8311
   │
   ├── brain.py   大脑：LLM 对话（OpenAI 兼容，默认智谱 GLM）
   │              · 四角色系统提示词（倾听/交流/分享/安抚 + 守护）
   │              · 情绪快扫：每条消息 → 情绪/强度/话题/风险/角色
   │              · 会话小结：每 8 轮 → 跨会话记忆
   │              · 深度人格分析：画像 vN → vN+1（大五 + 特质 + 证据）
   │
   ├── store.py   本地存储 data/（真正的数据源）
   │              · sessions/*.json  会话原文
   │              · persona.json     人格模型 + 情绪日志 mood_log
   │              · state.json       飞书文档映射 / pending 重试队列
   │
   └── feishu.py  飞书云文档（异步队列写入，失败落盘重试）
                  · 每天一篇 🌳 树洞 · MM-DD 周X   ← 对话记录
                  · 一篇   💎 树洞人格画像          ← 每次深度分析的快照
```

**关键取舍**：本地 `data/` 是 source of truth，飞书是「同步副本 + 人类可读的档案」。
所以飞书临时挂掉不影响聊天，恢复后队列自动补写。

## 三、飞书文档长什么样

**每日对话记录**（一天一篇，自动创建）：

```
🌳 树洞 · 09-11 周五
今天的心事，都讲给树洞听。树洞会认真记下每一句话 🌳
────────────────────────────
—— 新对话 · 14:30（被领导批评了）
第 1 轮 · 14:30
  🙋 我：
  今天被领导当众说了，项目延期的事全推到我头上……
  🌳 树洞：
  当众被说，这口气很难咽。你愿意跟我说说当时的场景吗……
  　· 情绪 委屈 72 · 话题 工作、领导 · 角色 安抚者
────────────────────────────
第 2 轮 · 14:33 …
📌 小结 · 15:02
  · TA 因项目延期被领导当众批评，感到委屈和焦虑
  · 聊到了和领导的信任问题，下周想找机会单独沟通（还没聊完）
```

**人格画像**（一篇长期文档，每次深度分析追加一节快照）：

```
💎 树洞人格画像
这份画像由「树洞挚友」根据对话记录自动分析与维护……
────────────────────────────
📋 画像 v3 · 09-11 22:00
一位高敏感、对自己要求很高的理想主义者……
# 核心特质
  报喜不报忧（78）—— 依据："没事，我自己能消化"
  对认可敏感（70）—— 依据："领导那句话我记了一整天"
# 大五人格估分
  开放性 78 · 尽责性 82 · 外向性 40 · 宜人性 70 · 神经质 58
# 情绪基调 / 在意的人和事 / 压力源 / 能量来源 / 偏好的沟通方式
# 树洞的陪伴备忘
  先接住情绪再谈事情；TA 说"没事"时往往最有事
```

人格模型（本地 `persona.json`）同时包含 `mood_log` 情绪日志，前端会画出最近 30 次的情绪轨迹条。

## 四、四重角色怎么切换

每条消息发送后、回复前，先用轻量模型做一次**情绪快扫**：

```json
{"emotion":"委屈","intensity":72,"valence":-2,"topics":["工作","领导"],
 "role":"soother","risk":"none","one_line":"被当众批评，憋着一口气"}
```

角色选择规则（自动档）：

| 信号 | 角色 | 姿态 |
|---|---|---|
| 自伤/绝望意图 | 🛡️ 守护 | 直接关心 + 热线 12356 / 010-82951332 / 400-161-9995 |
| 负面情绪强烈（≥70 且消极） | 🕊️ 安抚者 | 先接住情绪，短句、陪伴，不讲道理 |
| 负面中等强度、在倾诉 | 🫂 倾听者 | 复述确认、命名情绪，几乎不给建议 |
| 想听观点/经验/解释 | ✨ 分享者 | 真诚给观点和故事，平视不授课 |
| 中性/积极、想闲聊 | 💬 交流者 | 有来有回，可以不同意你 |

LLM 快扫失败时自动降级为关键词规则引擎（同样能识别危机词，绝不漏判高风险）。
手动点角色胶囊可强制指定。

## 五、快速开始

### 1. 安装依赖

```bash
cd ai-treehole
pip install -r requirements.txt
```

### 2. 配置飞书（约 5 分钟）

> 提示：如果你已经有别的飞书自建应用，直接复用它的 App ID / App Secret，
> 只需完成第 3~4 步给它补开文档权限即可；新建应用则从第 1 步开始。

1. 打开 [飞书开放平台](https://open.feishu.cn) → **创建企业自建应用**（免费，个人注册的飞书就行）
2. 「凭证与基础信息」页复制 **App ID / App Secret**，填进 `config.json`（或网页里的 ⚙️ 设置）
3. 「权限管理」开通（搜索后勾选，或直接点官方一键开通链接）：
   - `docx:document`（查看、评论、编辑和管理文档）——建/写对话文档与画像文档
   - `drive:drive`（查看、评论、编辑和管理云空间中所有文件）——建文件夹、查目录
4. **创建版本并发布**应用（不发布权限不生效）
5. 让应用能访问你的文件夹（推荐）：在飞书云文档里新建一个文件夹，比如「AI 树洞」→
   文件夹页面右上角「···」→ **更多** → **添加文档应用** → 搜索你的应用名 → 权限给「可编辑」→
   把**整个文件夹链接**粘贴进 `config.json` 的 `folder_token`（支持 `fld…` token 或完整链接两种写法）
6. 不想做第 5 步也行：`folder_token` 留空，应用会自动在自己空间建「🌳 AI树洞」文件夹；
   个人租户可再把 `auto_share_tenant` 设为 `true`，文档会被设为「组织内可编辑」方便你直接打开

配置好后可跑 `python _feishu_live_test.py` 做一次真实链路验证（建临时文档 → 写块 → 移入回收站）。

### 3. 配置对话模型

`config.json` 默认使用智谱 GLM（[open.bigmodel.cn](https://open.bigmodel.cn)），把 `api_key` 填上即可。
换成 DeepSeek / 通义 / OpenAI 等任意 OpenAI 兼容服务只需改 `base_url` + `model`。

### 4. 自检 & 启动

```bash
python app.py --check    # 自检：飞书连通 + 模型连通
python app.py            # 前台启动（调试用），自动打开 http://127.0.0.1:8311
```

**日常推荐：双击 `树洞开关.vbs`（无感开关）**——未运行时后台静默启动（无黑窗、约 2 秒就绪），
再双击一次即静默停止；日志写在同目录 `server.log`。想要看得见的调试窗口时再用 `start.bat`。

### 5. 开始聊

打开页面 → 直接说心里话。右上角「💎 画像」随时查看人格模型，「🔄 深度更新」让它重读最近的对话；
「🗂 心事」看历史会话；顶栏「📄 今日记录」直达当日飞书文档。

## 六、隐私与安全边界

- 服务只监听 `127.0.0.1`，对话数据只存在本机 `data/` 和你自己的飞书
- `config.json` / `data/` 均已 gitignore，**不会**进入 git 仓库
- 危机情况（自伤等信号）下，树洞会指向真实的专业资源（12356 等），但**不做诊断、不替代专业帮助**
- 飞书文档权限由你自己掌握：不共享，就只有你（和你授权的应用）能看到

## 七、文件结构

```
ai-treehole/
├── app.py               # FastAPI 服务：SSE 聊天管线 + 全部 API
├── brain.py             # 大脑：提示词 / 情绪快扫 / 小结 / 人格深度分析
├── feishu.py            # 飞书客户端 + 异步写入队列（失败落盘重试）
├── store.py             # 本地存储（会话 / 人格模型 / 状态）
├── static/              # 前端（index.html / style.css / app.js）
├── config.json          # 你的密钥配置（gitignored）
├── config.example.json  # 配置模板
├── data/                # 运行时数据（gitignored）
├── 树洞开关.vbs          # 无感开关：双击启动/再双击停止（推荐日常用）
└── start.bat            # 带窗口启动（调试用）
```

## 八、已知边界与可扩展方向

- 深度人格分析依赖文字信号，估分是「倾向」不是「诊断」，画像仅供参考
- 可扩展：飞书侧主动提醒（长期低落时推送一条问候）、多用户、语音输入、把画像导出为周报
- `TREEHOLE_MOCK=1 python app.py --check` 可在无密钥环境下做全链路联调
